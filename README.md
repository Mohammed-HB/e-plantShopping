# e-plantShopping

**Paradise Nursery** is a front-end shopping application for browsing and purchasing houseplants.

## Overview

e-plantShopping is an interactive plant shopping front end. It introduces visitors to Paradise Nursery, presents a catalog of houseplants organized by category, and supports a dynamic shopping cart where users can review items, adjust quantities, and prepare for checkout.

## Features

The landing page presents the Paradise Nursery brand with a full-page background image, a short company description, and a “Get Started” call-to-action that leads into the plant catalog.

The product listing page displays six or more houseplants across three or more categories. Each plant is presented with a thumbnail image, plant name, price, and an “Add to Cart” option.

The shopping cart page summarizes the selected plants with thumbnails, names, unit prices, item totals, the total number of plants, and the combined cost. Quantity controls and item deletion keep the cart contents flexible before checkout.

The header appears on the product and cart pages, includes navigation between those pages, and shows a shopping cart icon with a dynamic count of items in the cart.

## Pages

1. **Landing Page** — introduces Paradise Nursery and directs users to the product catalog.
2. **Product Listing Page** — displays the plant catalog and supports adding plants to the cart.
3. **Shopping Cart Page** — shows cart details, totals, and options for updating or checking out.

## Technologies

- Front-end web technologies: HTML, CSS, and JavaScript
- Component/state-based front-end implementation for product display and cart updates
- Responsive UI layout for desktop and mobile browsers

## Getting Started

To run the project locally, clone the repository and open the app in your browser or start your preferred front-end development server.

```bash
git clone https://github.com/Mohammed-HB/e-plantShopping.git
cd e-plantShopping
```

If the project uses a Node-based front-end workflow, install dependencies and run the development server:

```bash
npm install
npm start
```

## Project Goal

The project demonstrates a clean, user-friendly shopping flow for a plant nursery, including landing page navigation, categorized product browsing, dynamic cart updates, and interactive cart management.
